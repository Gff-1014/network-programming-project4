日期：2026-10-11
环境：Windows，Python 3.12.14，pytest 9.1.1 + pytest-asyncio 1.4.0（独立虚拟环境 `.venv`）

## 一、移植内容

| 上游文件 | 本项目 | 改动 |
| --- | --- | --- |
| `doudizhu/card.py` | `game/cards.py` | 去掉 Python 2 分支（`is_py3`、`cmp` 参数），改用 `functools.cmp_to_key` |
| `doudizhu/engine.py` | `game/engine.py` | 同上；去掉导入时对根 logger 的 `basicConfig`，改为模块级 logger |
| `doudizhu/__init__.py` | `game/__init__.py` | 重写门面；`new_game(seed)` 使用本地随机源，同一 seed 可复现同一副牌 |
| `doudizhu/compat.py` | 不移植 | 仅用于 Python 2 兼容 |
| `tests/test_card.py`、`test_doudizhu.py`、`test_game.py` | `tests/` 同名文件 | 仅改导入路径，用例内容保持原样 |
| `docs/engine.md` | `docs/牌型规则-上游说明.md` | 原样保留，作为牌型定义依据 |
| `LICENSE` | `game/LICENSE-onestraw.txt` | 原样保留版权声明 |

## 四、结论与已知差异

1. 牌型判定与比较直接复用上游实现，**不需要我们自行实现**，M2 的主要风险点消除。
2. 上游 `new_game()` 用 `random.seed()` 重置全局随机源，本项目改为 `new_game(seed)`，
   既保持可复现，又不影响调用方的随机状态。
3. `game/cards.py` 中保留了一个可选依赖 `termcolor`（仅在 `int_to_pretty_str` 内，
   且被 `try/except ImportError` 包裹），未安装时自动降级，不影响运行；客户端将用
   自己的牌面渲染，不依赖它。
4. 牌型字典在进程启动时构建一次，测试中测得总条目 34152，后续需要记录一次启动耗时
   作为服务端启动成本。
