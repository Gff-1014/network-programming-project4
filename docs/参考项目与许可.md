# 参考项目与许可说明

本项目在**游戏规则**部分直接复用了开源实现，网络层为自研。以下按用途列出。

## 一、已复用代码

| 项目 | 许可 | 复用什么 | 落在哪 |
| --- | --- | --- | --- |
| [onestraw/doudizhu](https://github.com/onestraw/doudizhu) | MIT (c) 2018 Larry He | 牌的表示、37 种牌型枚举、牌型识别与大小比较、可压牌列表 | `game/cards.py`、`game/rules.py`（原样移植，仅去掉 Python 2 兼容分支与导入期的 logging 配置；上游文件名 `engine.py`，为避免与自研的对局状态机重名而改为 `rules.py`） |

原许可证全文见 `game/LICENSE-onestraw.txt`，上游规则说明见 `docs/牌型规则-上游说明.md`。

本项目对上游的改动：

1. 仅保留 Python 3 实现，去掉 `compat.py` 与 `is_py3` 分支；
2. 去掉导入时对根 logger 的 `basicConfig`，改用模块级 logger；
3. 发牌改为 `new_game(seed=None)`，用本地随机源，同一 seed 可复现同一副牌。

## 三、作为反面案例

[Azuronis/Asyncio-TCP-Chat](https://github.com/Azuronis/Asyncio-TCP-Chat)（MIT）用于对照实验：
其全局单发送队列导致慢客户端阻塞全服、心跳判活失效、未登录连接断开后忙等拖垮事件循环。
本项目在设计上逐条规避这三类问题，实测数据见 `evidence/`。
